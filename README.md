# Qunoot Fatima — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

1. Open the repository's **Settings** on GitHub.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then select **Save**.

After GitHub Pages finishes deploying, the site will be available at:

<https://qunootfatima.github.io/Qunoot-Portfolio/>
